# LoopLeaf Website – Docs-Ordner

Dieser Ordner enthält die aktuelle Arbeitsgrundlage für den Nachbau der bisherigen Wix-Website als eigenständig programmierte Website.

Ziel ist eine einfache, stabile, responsive und gut wartbare statische Website für:

- **LoopLeaf** – App-Landingpage
- **Ryska Productions** – Projekt-/Studioseite
- **Datenschutz** – aus bereitgestellter Word-Datei
- **Impressum** – externer Link zum Impressumsdienst

## Empfohlene Nutzung mit Codex

1. Diesen `Docs`-Ordner ins Website-Projekt legen.
2. Screenshots der Wix-Seite zusätzlich im Projektordner ablegen, z. B. unter `/reference/screenshots/`.
3. Originalbilder, Logos und Icons unter `/assets/` bereitstellen.
4. Die Datenschutzerklärung als Word-Datei im Projektordner oder unter `/docs/source/` bereitstellen.
5. Codex zuerst nur die Analyse machen lassen.
6. Danach Schritt für Schritt umsetzen lassen.

## Wichtig

Diese Dokumente enthalten Design-, Struktur- und Textvorgaben. Sie ersetzen keine rechtliche Prüfung der Datenschutzerklärung, des Impressums oder des Cookie-/Consent-Banners.
