## Ziel der Website

Die Website soll die bisher mit Wix erstellte Seite als eigenständig programmierte Website nachbauen.

Sie soll:

- optisch nah an den Wix-Screenshots bleiben
- ruhig, warm, hochwertig und freundlich wirken
- die App LoopLeaf erklären
- Ryska Productions vorstellen
- eine Datenschutzseite enthalten
- ein externes Impressum verlinken
- eine gute mobile Ansicht besitzen
- ein technisch sauberes Cookie-/Consent-Banner enthalten
- eine Kopfzeile haben, die beim Scrollen nach unten verschwindet und beim Scrollen nach oben wieder erscheint

## Zielgruppe

Menschen, die Kontaktpflege als emotional oder organisatorisch anstrengend erleben und sich eine ruhige, nicht wertende Unterstützung wünschen.

Die Website soll besonders folgende Stimmung vermitteln:

- weich
- freundlich
- nicht drängend
- cozy
- naturverbunden
- klar
- vertrauenswürdig
- privat und sicher

## Technische Grundidee

Die Website soll möglichst einfach und statisch umgesetzt werden.

Empfehlung:

- HTML
- CSS
- JavaScript
- kein Backend
- keine Datenbank
- keine unnötigen externen Dienste
- keine Trackingdienste
- keine komplexe Build-Umgebung, wenn sie nicht nötig ist

## Grundseiten

1. `index.html` – Startseite / LoopLeaf
2. `ryska.html` – Über Ryska Productions
3. `datenschutz.html` – Datenschutzerklärung
4. Impressum als externer Link
